Créditos

O Combina Jogos é um projeto pessoal desenvolvido por Vinicius Coelho e Amaro Coelho, com o objetivo de gerar e gerenciar jogos de loteria de forma prática.

A ideia surgiu da vontade de ter uma ferramenta própria para organizar apostas, aplicar estratégias de números fixos e mais sorteados, e conferir resultados rapidamente.

Histórico de versões

Versão Tecnologia Descrição
v1 Java Primeira versão, não versionada
v2 JavaScript Versão web pura, sem backend, não versionada
v3 Go + PostgreSQL API REST, persistência em banco, interface web completa
